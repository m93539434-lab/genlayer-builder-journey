# GenLayer Fundamentals

## 1. What is GenLayer?

GenLayer is an intelligent blockchain designed for applications that need to make decisions using natural language, live web data, AI models, and other non-deterministic inputs.

## 2. What are Intelligent Contracts?

Intelligent Contracts are Python-based contracts that can combine traditional deterministic logic with AI-powered and external-data operations.

They allow developers to build applications that require more than fixed, rule-based computation.

## 3. Core Components

### GenLayer Chain
Coordinates transactions and records authoritative consensus information.

### Validator Nodes
Execute assigned tasks and independently evaluate proposed contract results.

### GenVM
A WebAssembly-based environment for executing Intelligent Contracts.

## 4. Optimistic Democracy

Optimistic Democracy is GenLayer's consensus mechanism.

A selected leader proposes an execution result. Other validators evaluate the proposal. If the required consensus is reached, the result can be accepted.

The protocol also provides an appeal process for eligible decisions.

## 5. Equivalence Principle

The Equivalence Principle defines how validators determine whether a non-deterministic result is acceptable.

Validators do not simply trust the leader. They independently verify the result according to the contract's validation rules.
