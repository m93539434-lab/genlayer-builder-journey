
# Project 02 — AI-Powered Product Verification DApp

## Project Overview

An educational decentralized application built with GenLayer Intelligent Contracts.

The application evaluates user-submitted product claims against supplied evidence and produces a structured verification result.

## Core Objective

Evaluate whether the submitted evidence supports a product claim.

## Verification Outcomes

- SUPPORTED
- UNSUPPORTED
- INSUFFICIENT EVIDENCE

## Example

Product: Wireless Headphones

Claim: Battery life is up to 40 hours.

Evidence: Manufacturer-provided product specifications.

The Intelligent Contract evaluates the evidence and produces a verification decision.
